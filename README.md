# Library Management System

A Windows desktop app for running a library.

- Sign in and create accounts
- Add, edit and delete books, with cover images
- Issue books to students and take them back
- Chart of books by genre

## Tech
C# · Windows Forms · .NET Framework 4.7.2 · SQLite

## Run
Open `Library.sln` in Visual Studio, restore NuGet packages, then press **Start**.
